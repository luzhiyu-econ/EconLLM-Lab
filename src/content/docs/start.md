本书从经济学研究中常见的文本整理任务出发。目标不是介绍模型内部原理，而是把一个可复核的流程跑通：明确要提取什么、调用模型、核对输出，再决定能否用于分析。

## 你将完成什么

贯穿案例使用上海市 2019—2023 年政府工作报告，提取**报告当年提出的全市经济增长目标**。最终得到按“城市—报告年份”排列的表，同时保留目标原句和人工复核记录。

只想先体验结果，可以直接运行[离线案例](../cases/growth-target/)；它不需要 API 密钥。准备接入模型时，再学习[环境配置](../guide/environment/)与[调用 API](../guide/api/)。

## 建议顺序

1. **配置环境**：确认终端、Git、Python 和项目环境能工作。
2. **调用 API**：理解请求、回复、费用和密钥的边界。
3. **定义任务**：先确定观察单位、字段与缺失规则，再写提示词。
4. **从文本到数据**：保存原文、原始回复和解析结果。
5. **评估质量**：用人工复核样本计算错误率，检查异常年份。
6. **用于研究**：说明变量的含义、覆盖范围和测量误差。

## 所需基础

会打开终端、编辑文本文件、运行一条命令即可。示例使用 Python 标准库，安装依赖时不要求购买任何 API 服务。所有需要在线调用的步骤都标明了环境变量与可能产生的费用。

如果你正在寻找 RAG、MCP 或多智能体内容，先看[后续主题](../roadmap/)；这些主题尚未写成可运行的教程，因此没有放进主线。
