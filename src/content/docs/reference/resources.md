本书优先链接稳定的官方文档。模型、价格、参数和服务界面会变化，操作前以供应商当前文档为准。

- [Python 官方教程](https://docs.python.org/3/tutorial/)：基础语法与标准库。
- [uv 官方文档](https://docs.astral.sh/uv/)：项目环境、锁文件与运行命令。
- [Git 官方文档](https://git-scm.com/doc)：版本管理。
- [Astro 文档](https://docs.astro.build/)与 [Starlight 文档](https://starlight.astro.build/)：本站建设和内容编辑。
- [上海市政府工作报告索引](https://www.shanghai.gov.cn/nw12336/)：案例的官方文本来源。

旧站章节、2025 年课程讲义、笔记本和第三方论文保存在仓库的 `archive/`，不在站点直接提供下载入口。它们是历史材料，旧示例中的模型调用、路径和数据标签未经逐项更新；请从本版案例开始学习。

网站源码、更新方式及许可说明见 [GitHub 仓库](https://github.com/luzhiyu-econ/EconLLM-Lab)。
