[MixtapeTools](https://github.com/scunning1975/MixtapeTools) 由经济学者 Scott Cunningham 整理，收录了他使用 Claude Code 开展研究、教学和报告的工具与经验。其中包括实证代码核查、R、Stata 与 Python 之间的结果复现、参考文献检查、论文分块阅读和 Beamer 演示文稿制作。初次阅读可以从仓库中的工作流程说明入手，再查看具体技能如何安排执行步骤与结果核验。

[claude-skills-public](https://github.com/amatray/claude-skills-public) 面向学术经济学研究，提供论文审阅、代码检查、文献综述核验、LaTeX 编译和经济模型求解等技能，也包含提示整理与研究计划审阅。每项技能以独立目录保存，并通过其中的 SKILL.md 说明任务要求。适合选取与当前工作接近的技能，阅读其输入、步骤和输出约定，再结合项目的软件环境与写作要求使用。

*资料核验于 2026 年 10 月 23 日。*
