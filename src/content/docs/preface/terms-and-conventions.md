---
title: 术语与约定
description: 本书关于 AI、大语言模型、文本标注与智能体的用语约定。
---

本书所称的 AI，特指生成式大语言模型（Large Language Model，LLM）。下文中的“AI”与“大语言模型”沿用这一约定。

| 术语 | 英文或缩写 | 本书中的用法 |
| --- | --- | --- |
| 大语言模型 | Large Language Model，LLM | 本书讨论的、能够依据输入上下文生成语言内容的大规模语言模型。 |
| 自然语言处理 | Natural Language Processing，NLP | 运用计算方法处理和分析人类语言，包括文本表示、分类、信息抽取与聚类等工作。 |
| Transformer | [Transformer](https://arxiv.org/abs/1706.03762) | 以注意力机制组织序列信息的神经网络架构，是后文讨论上下文表示与生成式模型的重要技术基础。 |
| 嵌入 | Embedding | 将词语、句子或文献表示为数值向量，以便比较和分析它们之间的关系。 |
| 提示词 | Prompt | 提供给模型的任务说明、材料、示例及输出要求。 |
| 标注手册 | Codebook | 对标签的含义、判断依据、适用条件和例子作出的明确约定。 |
| 模型标注 | [LLM-based annotation](https://arxiv.org/abs/2303.15056) | 让大语言模型依据标注规则，为文本赋予类别、分数或其他结构化标记。 |
| 模型评判 | [LLM-as-a-Judge](https://arxiv.org/abs/2306.05685) | 让大语言模型依据给定标准评价内容或比较候选回答。后文将结合文本标注讨论如何说明和验证判断标准。 |
| 模拟主体 | Simulated agent | 在实验或模型设定下作出经济选择的行动者。本书关注用大语言模型生成其决策的做法。 |
| 研究智能体 | [AI agent](https://www.anthropic.com/research/building-effective-agents) | 以大语言模型为核心，根据任务目标、工具结果与环境反馈安排并执行研究步骤的系统。 |
| 微调 | Fine-tuning | 通过进一步训练调整模型参数，使模型适应特定任务或行为要求。 |

后文中的 agent 有两种使用情境：在经济模拟中，它是研究所考察的行动主体；在研究实践中，它是协助研究者执行任务的工具。具体含义随所在章节说明。
