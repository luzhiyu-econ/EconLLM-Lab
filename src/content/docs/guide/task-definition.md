让模型“提取经济增长目标”仍然过于含糊。报告常同时回顾上一年、提出当年目标、讨论五年规划。若不先规定取哪一个，数字即使正确，也可能落在错误年份。

## 观察单位与字段

本案例每一行是**上海市的一份年度政府工作报告**，主键为 `city`、`report_year`。目标字段是报告对**当年全市生产总值增长**提出的预期目标，不是上一年实际增速，也不是财政收入、投资或产业增加值的目标。

| 字段 | 含义 |
| --- | --- |
| `target_quote` | 原文中支持判断的最短完整句段 |
| `target_expression` | 原文目标表达，如“6%以上” |
| `target_value` | 便于比较的数值部分，如 `6.0` |
| `target_min`、`target_max` | 区间目标的上下界；非区间留空 |
| `target_qualifier` | “以上”“左右”“区间”等限定词 |
| `status` | `found`、`missing`、`uncertain` 或 `failed` |

`target_value` 不是对实际增长率的预测，也不能单独替代原文表达。2019 年报告使用区间目标，示例将其上下界分别存入 `target_min`、`target_max`，不取中点。无法判定的表达标记为 `uncertain` 并交人工处理。

## 判定顺序

1. 查找“今年”“本年度”对应的**预期目标**段落。
2. 核对它描述的是全市生产总值或地区生产总值增长。
3. 保留包含数值和限定词的原句，不用单个百分数代替证据。
4. 报告确无该目标时记 `missing`；有候选但年份或口径不清时记 `uncertain`；请求或解析异常记 `failed`。

提示词只负责提出候选答案；这些规则决定能否接受候选。规则与示例一起固定在代码里，便于以后更换模型时比较结果。
