---
title: 评估提取质量
description: 区分字段正确、缺失、歧义与调用失败
---

程序能生成 CSV 不等于变量已经可用。评估需要先定义人工标准，再计算模型结果与标准的差异。五份示例报告适合学习流程，不足以证明方法在其他城市或年份也可靠。

## 建立人工标准

复核者逐份阅读目标段落，记录原句、表达、年份和判断理由。对有歧义的报告保留候选与争议，不通过“猜一个值”消除歧义。标准表放在案例的 `fixtures/expected.json`，与固定模型回复分别保存。

## 至少检查四类错误

| 检查项 | 错误例子 |
| --- | --- |
| 年份 | 把上一年实际增速当成本年目标 |
| 指标 | 把财政收入目标当作 GDP 目标 |
| 数值与限定词 | 把“6%以上”写成“6%”且丢失“以上” |
| 状态 | 将未找到、无法判断和调用失败合并为 0 |

对已人工确认有目标的行，分别计算目标识别率和数值、限定词的准确率。分母应写清楚：例如“有目标的复核报告数”，而不是全部模型调用数。失败调用单独报告，再决定是否重试；不能从准确率分母中悄悄删除。

## 超出示例样本时

正式批量任务应从不同年份、地区和文本格式抽取复核样本，记录抽样方法。先检查错误是否集中在特定表述，再调整提示词或解析规则，并在保留的样本上重新比较。若一轮修改使用了评估样本，另留一组最终检验样本。

完成评估后，阅读[用于经济学研究](../research-use/)中的合并与解释边界。
