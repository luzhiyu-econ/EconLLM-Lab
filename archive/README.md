## 已确认的问题

- `lectures/2505/notebooks/data/政府工作报告/上海市/2019.txt` 与 `2020.txt` 的文本相似度约 99.98%，均包含与上海市政府正式 2019/2020 报告不同的目标表述。不能按文件名直接作为当年市级报告。
- 同目录 `2022.txt` 的正文明确写着“青浦区人民政府”，是区级报告，不能作为上海市级报告。
- 两份 `llm_report.pdf` 的 SHA-256 完全一致，保留 `lectures/2505/llm_report.pdf` 一份。校验值记录在 `archive/checksums.txt`，不混入结果表。
- 历史笔记本中的旧密钥、输出及模型接口不能作为当前调用示例。公开的笔记本已清理密钥字面量；旧提交留作历史。

新案例只使用逐年对照[上海市政府工作报告索引](https://www.shanghai.gov.cn/nw12336/)后的短节选。第三方论文与讲义遵循原作者许可，不作为本站下载资源提供。
